## 选题1：💼【职场认知类 - 2026年"AI不会抢走你的工作，但会重写你的岗位说明书"：国办18项任务背后的就业真相】（上午发布）

**开头钩子**：2026年10月，一份文件让很多人重新看了一遍自己的岗位：国办发文减缓人工智能就业替代影响，部署了6个方面18项主要任务，同时加快开发人工智能领域的新职业。研究者说得更直接：真正在发生的，不是"AI把谁换掉"，而是"AI把每个岗位的说明书重写了一遍"。最反直觉的一点是——替代速度在不同岗位之间差异极大：软件开发、代码编写在以很快的速度被替代，而大量传统岗位反而相当缓慢。所以真正该问的问题不是"我会不会被替代"，而是"我的岗位里，哪一部分正在被重写"。

**视频类型**：职场认知 + AI 趋势 + 个人成长
**时长**：50-65秒
**节奏**：热点解读 + 安全感重建，带"原来我该担心的不是失业，而是我的工作方式过时了"的清醒感与底气

**定人**：职场博主 / AI 博主 / 知识管理博主
**定景**：十月下旬周二上午10点的家中书房或共享办公位 + 一台打开笔记本电脑（屏幕上是岗位说明或行业数据页面） + 一杯热咖啡 + 摊开的笔记本和一支笔 + 十月下旬上午清冷明亮的自然光 + 简约衬衫或深色针织 + 神情清醒但不焦虑 + 略带"想清楚了方向"的笃定

**分镜脚本**：
1. 0-10秒：反常识开场（"2026年10月，一份文件让很多人重新看了一遍自己的岗位：国办发文减缓人工智能就业替代影响，部署了6个方面18项主要任务，同时加快开发人工智能领域的新职业。研究者说得更直接：真正在发生的，不是'AI把谁换掉'，而是'AI把每个岗位的说明书重写了一遍'。最反直觉的一点是——替代速度在不同岗位之间差异极大：软件开发、代码编写在以很快的速度被替代，而大量传统岗位反而相当缓慢。所以真正该问的问题不是'我会不会被替代'，而是'我的岗位里，哪一部分正在被重写'"）
2. 10-25秒：真正的变化在哪（"变化到底在哪？三个事实：第一，'替代总量很慢，替代结构很快'——新技术对就业总量的影响可能比较缓慢，但不同岗位差异极大，真正剧烈的重写发生在具体环节，而不是整个职业一次性消失；第二，'新职业已经出现'——国办明确要求加快开发人工智能领域的新职业，机会不在'旧岗位消失'，而在'旧职业长出新岗位'，AI训练师、AI产品评估、AI流程运营已经从概念变成招聘里的正式头衔；第三，'社会成本要提前部署'——培训成本、转岗成本都是真实的，清华学者提醒这不是技术问题而是部署问题；本质上：与其担心岗位消失，不如提前把自己搬进新岗位")
3. 25-40秒：三步把自己搬进新岗位（"三步——第1步（15秒）'把岗位拆成环节'：拿一张纸，把你现在的工作拆成五到八个具体动作，逐个标注'AI能不能替'、'AI能不能提效'、'只有人能做'，你会立刻看到重写发生在哪几格；第三步（10秒）'让AI接管可描述的部分'：凡是能被一句话说清楚的动作，就能被自动化——先从报表、检索、初稿、对账这类高频小事开始；第3步（15秒）'往人的那一格堆'：判断、责任、关系、协调、拍板，这五个格子在可见的将来最难被替代，把时间挪过去；数据：主动完成AI转岗培训的人，薪资中位数高出未培训者约30%"）
4. 40-55秒：长期复利（"长期回报：第一，'你的焦虑从模糊变成具体'——你不再担心'会不会失业'，而是知道'今年该练哪个格子'，具体永远比模糊让人安心；第二，'你的可迁移性在提高'——能被拆解说明书的岗位，才是抗替代的岗位；第三，'你会从执行者变成设计者'——定义清楚、验收标准明确的人，永远比埋头做的人更安全；一句话：2026年最聪明的职业策略，不是跟AI抢活，是把自己的岗位说明书重新写一遍，让AI成为你说明书里的一个变量"）
5. 55-65秒：账号引导（"关注我，2026职场与AI——岗位拆解、能力迁移、以及普通人怎么接住这一轮重写"）

**BGM建议**：十月下旬周二上午的清醒与专业感 + 稳中向前的推进感，简约电子节拍或轻微钢琴铺底，带"方向清楚了"的安定与底气

**视频类型**：关系心理 + AI 观察 + 情绪疗愈
**时长**：50-65秒
**节奏**：温柔洞察 + 平静收束，带"原来我想要的不是一个更懂我的AI，而是被一个真人惦记"的清醒与释然

**定人**：情感博主 / 心理学博主 / 生活方式博主
**定景**：十月下旬周二晚上9点的家中客厅角落或书桌 + 一盏暖黄的落地灯或台灯 + 手机屏幕朝下扣在桌面 + 一杯温热的花茶 + 一本翻开的书 + 窗外安静的秋夜与远处点点灯光 + 宽松的米色家居服 + 沉静若有所思的神情 + 安静松弛的居家氛围 + 略带"想明白了"的平和

**分镜脚本**：
1. 0-10秒：反常识开场（"2026年，一个被反复讨论的现象是：AI陪伴正在成为一代人的深夜出口——据第三方口径，陪伴类应用月活已达约2000万，全球陪伴类应用年收入约1.2亿美元；与此同时，一项针对年轻人的研究发现，对话式AI的使用与社交焦虑、孤独感、生活质量之间存在复杂关联。更值得玩味的是监管的态度：我国《人工智能拟人化互动服务管理暂行办法》明确要求AI必须标识非人类身份，不得过度迎合用户、诱导情感依赖。也就是说，技术在学会更像人，而规则在提醒我们：它不是"）
